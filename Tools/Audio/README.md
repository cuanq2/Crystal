# 洞穴脚步声替代素材

`generate_cave_step.py` 用 Python 标准库合成石地面落脚和短回声，提供缺失的 `Sound/22.wav` 替代音效。声音全部由固定种子的噪声、正弦波和延迟叠加生成，没有下载、复制或改编第三方录音；它不是找回的原版素材。

在仓库根目录运行：

```powershell
python Tools/Audio/generate_cave_step.py
```

默认生成 `release/Client/Sound/22.wav`，已有文件时拒绝覆盖。可用 `--output <文件路径>` 输出试听版本。格式为 44.1 kHz、16 位 PCM、单声道，时长 0.66 秒；峰值约 0.089，参照现有 `21.wav`、`23.wav`、`24.wav` 的格式和峰值设置，未使用这些文件的音频内容。

配套 `SoundList.lst` 应包含 `10022: 22.wav`，客户端据此将 `WalkCaveR` 定位到该文件。生成脚本不创建或改写声音映射表，也不向远端部署。仅生成此文件不代表其他游戏资源已补齐。最终音色及与左脚声的协调程度需要进游戏试听。
